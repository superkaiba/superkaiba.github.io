# Revisiting cognitive tests of System 1 and System 2

[Early cognitive-reflection experiments](https://doi.org/10.1038/s43588-023-00527-x) found that newer chat models avoided many intuitive mistakes made by earlier models. A [2025 follow-up using modified problems](https://escholarship.org/uc/item/24x9t7s1), including tests of o1, found substantial errors when familiar problems were changed. Success on the standard question and robust reasoning through a new version can therefore give different pictures.

It seems important to revisit these tests with current reasoning models and controlled reasoning budgets, asking when deliberation actually corrects an intuitive response. “System 1” and “System 2” would be behavioral hypotheses to test, rather than names assigned automatically to short and long answers.

- Reproduce existing cognitive-reflection and semantic-illusion tests, then generate new variants with checked answers.
- Compare matched questions where an intuitive answer conflicts with the correct answer and where it does not.
- Vary available reasoning time or tokens, measuring error correction as well as final accuracy.
- On open models, track candidate intuitive and correct answers internally, testing whether reasoning changes their relative support.
