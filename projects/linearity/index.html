How linear are LLM representations?

There is a lot of literature suggesting that parts of LLM computation are more linear than we might expect:

  • Neural sentence trajectories become straighter as they pass through trained language models.
  • Jump to Conclusions studies linear transformations that approximate the relationship between intermediate and final representations.
  • The Linear Representation Hypothesis examines how concepts can be represented as directions.
  • Transferring Linear Features Across Language Models studies linear mappings between different models' representations.

These are related observations, but they concern different kinds of linearity: across tokens, across layers, across concepts, and across models.

The goal of this project would be to characterize these relationships and see whether they can help us build simple models of LLM behavior, generation, or training. If we can describe part of the computation with a linear map, we can bring in tools from dynamical systems and other well-developed areas of mathematics.

In my newest paper, we find a linear map from context to answer representations. Some directions to build on this:

  • Understand how fine-tuning changes the map.
  • Test whether changes in the map predict changes in behavior.
  • Identify what the map predicts well and what actually requires nonlinearity.
  • Find out when a good predictive approximation also gives a useful causal explanation.
