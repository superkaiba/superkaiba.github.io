How features combine and separate across transformer layers

Not started

Matryoshka SAEs learn features at several levels of abstraction within a chosen activation site. Cross-layer transcoders connect sparse features across transformer depth, but do not explicitly organize those features into a semantic hierarchy. Work on stages of inference suggests that intermediate layers build semantic representations while later layers increasingly turn them into token predictions.

It would be useful to train sparse features jointly across layers with an explicit preference for an hourglass structure: earlier features combine into more abstract middle-layer features, which then branch into more concrete, output-specific features. The later stage need not recover the original inputs. The question is whether this structure makes the learned features and their interactions more faithful to the model. The location of the most abstract features should remain a hypothesis to test, rather than a conclusion guaranteed by the architecture.

  • Keep the transformer frozen and learn sparse representations that reconstruct its activations at several depths, connected by sparse nonlinear mappings. Preserve attention-mediated interactions when connecting features across token positions.
  • Encourage composition before a middle region and branching afterward, while allowing persistent features and paths that carry details past that region. Compare fixed and learned transition depths.
  • Compare this preference with unconstrained cross-layer connections and a hierarchy that only builds toward greater abstraction, using comparable parameter and sparsity budgets.
  • Measure abstraction through stability across changes in wording or other irrelevant details, rather than dictionary size alone. Test whether intervening on a middle feature produces the predicted changes in downstream features and outputs in the original model.
  • Start with a small model whose intermediate computations are known, then test a pretrained language model. Check for skipped intermediate computations, since accurate reconstruction alone does not establish a faithful explanation.
