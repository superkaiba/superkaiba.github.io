# Personas as persistent features

**TL;DR:** Measure which persona traits and features persist throughout an answer and across later responses, then test how cached context and generated text sustain them. Start with sycophancy and compare it with the original evil and hallucination persona directions.

[Persona features](https://arxiv.org/abs/2506.19823) and [Persona Vectors](https://arxiv.org/html/2507.21509v3) identify directions associated with broad behavioral traits. Work on [Persistent Sparse Autoencoders](https://arxiv.org/html/2607.17117v2) measures different timescales for ordinary sparse autoencoder features and learns a retention coefficient for each feature. A [report on emotion-feature persistence](https://latentaffect.animalabs.ai/long_range_persistence_of_emotion_features.html) measures correlations over 100 tokens and effects after brief steering pulses. These results motivate a matched comparison of persona traits, rather than a claim that feature persistence itself is new.

When a model becomes sycophantic, does the corresponding direction stay active, reactivate only at relevant words, or continue to influence later behavior even when its projection falls? A persistent signal could reflect a lasting behavioral tendency, an unchanged topic, or repeated wording. Distinguishing these possibilities would make persona monitoring and steering easier to interpret.

The central hypothesis is that validated persona directions have different, reproducible persistence profiles after controlling for topic, token position, and activation variance. This would be weakened if the differences disappear under matched controls, depend on one extraction sample, or fail to predict later trait expression. The reviewed work does not establish this specific comparison of the original persona vectors, but that gap needs confirmation before committing to a paper.

- **Validate the traits before measuring persistence.** Keep vector extraction, calibration, and evaluation prompts separate. Check held-out behavioral prediction and positive versus negative steering. For sycophancy, distinguish unjustified agreement with an incorrect user from appropriate agreement with a correct user. A failed probe is not evidence that the trait has no persistence.
- **Separate continuous activity from later reactivation.** Trace projections at every answer token. Measure consecutive active runs, the fraction of tokens above a calibrated threshold, lagged correlation, and conditional above-baseline activation at distances from 1 to 512 tokens. Report the full curves, including bursts and sign reversals, and estimate a half-life only when a suitable decay model fits.
- **Compare persistence across responses.** Use matched neutral, trait-inducing, and opposing contexts across topics, followed by fixed neutral questions that either continue or change the topic. Measure whether the first answer predicts activation and independently scored behavior in the next two answers. Also track prompt tokens and test evidence that should change the persona, without keeping a trait instruction active in the system prompt.
- **Test whether a brief intervention has a lasting effect.** Steer a validated direction for five assistant tokens, then stop. Compare positive and negative pulses with sham and random-direction controls at calibrated strengths. Measure signed projection changes 100 tokens later and trait behavior in the next neutral response. A lingering projection alone does not establish a lasting behavioral effect.
- **Separate cached activation history from text feedback.** Compare free generation with branches forced to process identical tokens. After the pulse, retain the affected KV cache in one branch and rebuild it from the same text without steering in another. Their difference measures an effect of intervention history beyond the identical text. Replaying naturally generated steered transcripts without intervention tests how much the wording can reproduce the later effect.
- **Compare persona features with other feature types.** Include topic features, local word or syntax features, and variance-matched random directions. Where compatible dictionaries exist, measure ordinary SAE features aligned with the persona vectors. Compare them with learned persistent features and directions preserved by token-to-token activation maps, while keeping temporally smoothed SAE states separate from evidence of natural persistence.
- **Check whether the ranking generalizes.** Start with an open 7–8B instruction model and replicate the main contrast on a second model family. Bootstrap whole prompt families, report valid sample counts at each lag, and treat answer endings as censoring rather than zero activation. Show globally centered and within-response-centered results separately, because removing a response's mean also removes potentially meaningful stable persona information.

A first pilot would use 30 prompt families per trait, three context conditions, and two sampled continuations. It would validate the measurement, profile compute costs, and set the sample size and smallest meaningful effect before the main study. A tentative six-week study would progress from validation and natural trajectories to pulse experiments, text and cache controls, and replication. SAE expansion can remain optional if compatible dictionaries are unavailable.

The deliverable would be a reproducible comparison showing which traits persist, over what distances, and under which controls, paired with behavioral measurements. A null result would be informative if validated probes and narrow uncertainty intervals rule out meaningful persistence differences. Otherwise, the result should remain inconclusive rather than assigning a trait a permanent persistence label.
